# 使用内容快照和标准化差异检测复查变化

复查先对官方页面生成标准化内容快照和 hash；hash 未变化时跳过 AI 生成。只有来源快照发生变化时，系统才生成候选内容，并将候选结果与当前 item 做标准化 diff；没有实质差异时不创建提案。这样可以降低调用成本，避免 AI 措辞波动或 HTML 噪声造成重复提案。

## Considered Options

- **每次抓取都调用 AI 并比较结果**：实现直观，但成本高且容易产生重复提案。
- **只比较原始 HTML**：对页面格式、脚本和追踪参数变化过于敏感。
- **标准化快照 hash + 内容 diff**：兼顾成本、稳定性和审核质量，当前采用此方案。
