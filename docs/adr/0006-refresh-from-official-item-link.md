# 已有 item 复查以官方产品链接为内容来源

`refresh-existing-items` 只抓取 item 的 `link` 生成内容更新提案；`sourceUrl` 只记录最初发现该 item 的外部目录页面，用于溯源和审计，不参与内容生成。如果官方链接不可访问，复查跳过该 item 并记录失败，不使用聚合站页面作为内容回退来源。这样可以避免把 MOGE、AI With Me 等目录的旧文案或二次生成内容重新写回项目。

## Considered Options

- **使用官方 `link`**：内容来源最接近产品事实，当前采用。
- **优先使用 `sourceUrl`**：容易获得页面，但会把聚合站内容当成事实来源。
- **两者混合生成**：来源边界不清，难以解释提案中的内容来自哪里。
