# 接受提案时校验正式 item 版本

接受内容更新提案时，系统必须重新读取正式 item，并同时校验提案创建时保存的 `_updatedAt` 与标准化内容 hash。任一不一致，提案都标记为 `stale`，不能覆盖当前 item；需要重新抓取并生成新的提案。这样可以避免审核等待期间的人工编辑被旧提案覆盖。

## Considered Options

- **接受时直接覆盖**：流程简单，但会丢失审核等待期间的人工修改。
- **只比较 `_updatedAt`**：能发现文档变化，但无法表达内容基线。
- **版本和内容 hash 双重校验**：同时保护文档版本与内容基线，当前采用此方案。
