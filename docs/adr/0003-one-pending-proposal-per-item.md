# 每个 item 同时只保留一条待审核更新提案

同一个 item 已经存在 `pending` 内容更新提案时，后续复查不得创建第二条提案，也不得覆盖当前提案；本次复查跳过该 item，等当前提案被接受或拒绝后，再基于最新正式内容生成下一条提案。这样可以保持审核上下文稳定，并避免多个提案按不同顺序写入同一个 item。

## Considered Options

- **覆盖现有提案**：结果更新，但会静默改变审核者正在查看的内容。
- **允许多条并行提案**：保留全部信息，但需要定义冲突、顺序和合并规则。
- **单条 pending，后续跳过**：审核边界最清晰，当前采用此方案。
