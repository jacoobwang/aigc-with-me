# 自动复查只覆盖自动导入的已发布 item

首版 `refresh-existing-items` 只处理已经发布且 `autoImported == true` 的 item，并要求它们仍然具备有效的产品链接。用户提交、付费提交或人工维护的 item 不自动进入复查范围，除非未来增加明确的主动授权。这样可以保证自动复查只作用于拥有明确来源链路的内容，避免覆盖提交者或编辑团队刻意维护的文案。

## Considered Options

- **复查所有已发布 item**：覆盖面大，但会改变用户或商业提交的内容所有权边界。
- **只复查自动导入 item**：范围可控、来源明确，当前采用此方案。
- **全部依赖显式 opt-in**：最灵活，但当前还没有授权字段和管理流程。
