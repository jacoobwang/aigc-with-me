# 复查提案不控制 item 生命周期和运营字段

`refresh-existing-items` 可以为内容字段生成整体更新提案，但提案接受时不得改变 item 的发布、审核、套餐、赞助或曝光控制。`name` 和 `link` 可以作为内容变化被记录和审核，但应用时必须经过条目标识与 URL 兼容性校验；自动复查不能借此改变发布边界或商业权益。

## Considered Options

- **所有字段都可应用**：实现路径短，但会让定时抓取任务拥有发布、下架和商业展示控制权。
- **所有字段都禁止自动提案**：安全，但无法处理名称、链接等真实内容变化。
- **内容提案与生命周期/运营控制分离**：保留内容更新能力，同时保护发布和商业边界，当前采用此方案。
