# 已有条目更新采用提案审核模式

`refresh-existing-items` 发现已有工具的内容变化时，先创建内容更新提案，由人工接受或拒绝后再修改正式条目；自动任务不得直接覆盖已发布内容。这样可以保留来源、旧值和新值的审计边界，避免 AI 生成错误、目标网站临时异常或页面改版直接影响线上目录，同时与现有“提交/编辑后重新审核”的内容生命周期保持一致。

## Considered Options

- **直接更新正式条目**：实现简单，但无法安全处理不可信的抓取和 AI 结果。
- **创建内容更新提案**：增加审核和存储成本，但能支持 diff、拒绝、重试和逐步放量，因此被采用。
